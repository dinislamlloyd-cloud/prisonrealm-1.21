# Prison Kingdom для Minecraft 1.21.11 (Fabric)

Нужны Fabric Loader 0.19.3+ и Fabric API для 1.21.11. Java 21.

## Сборка через GitHub
1. Создайте новый пустой репозиторий (например, `prisonrealm-1.21`).
2. Загрузите все файлы из архива (Add file → Upload files), затем Commit changes.
3. Создайте файл `.github/workflows/build.yml` (Add file → Create new file) и вставьте содержимое `build.yml` из архива.
4. Вкладка Actions → дождитесь зелёной галочки → внизу Artifacts → `prison-kingdom-mod-1.21.11`.
5. В архиве возьмите `prisonrealm-1.0.0.jar` (не `-sources`) и положите в `mods` вместе с Fabric API.

## Что в моде
- **Запечатывающий куб** — работает на игроках и мобах. ПКМ кубом по цели (или в воздух, глядя на цель): раскрывается печать-крест с глазом и держит цель щупальцами, через 3 секунды исчезает, и вокруг цели появляются шесть красных кубов с глазами. Ещё раз ПКМ (или «close» в чат): кубы наваливаются на цель и смыкаются в один куб. Остаётся голубой куб; любой игрок в 2 блоках пишет **open** — цель выходит.
- Крафт куба: выбросите (Q) рядом 3 обсидиана и 3 красных красителя, или скрафтите их на верстаке.
- **Наручники** и **дубинка стражника**.
- **Тюремный мир** — плоская равнина из песка душ. Заключённый выходит по сроку, по «open» или по команде оператора.

## Команды
- `/prison arrest <игрок> [минуты]`, `/prison seal <игрок>`, `/prison release <игрок>`, `/prison list` (оператор)
- `/prison time`

## Отличия от версии 1.20.1
- Запечатанный моб не исчезает из мира, а стоит невидимым внутри голубого куба, пока куб не откроют.
- Тюремных блоков-решёток, ворот и ключей больше нет (тюрьма теперь — равнина из песка душ).
